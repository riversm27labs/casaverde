# Ficha comercial para aprovação do proprietário

Preencher com informações oficiais. Esta ficha não publica conteúdo nem ativa preços automaticamente. Não coloque senhas ou chaves neste arquivo.

| Informação | Preenchimento/aprovação |
| --- | --- |
| Nome comercial | A confirmar pelo proprietário |
| Razão social/documento empresarial, se aplicável | A fornecer |
| E-mail administrativo do proprietário | A fornecer; não há OWNER_EMAIL hospedado configurado |
| Telefone e WhatsApp oficiais | A fornecer |
| Endereço, cidade e região atendida | A fornecer |
| Horários | A fornecer |
| Redes sociais oficiais | A fornecer |
| Domínio desejado e titular | A fornecer |
| Projeto/conta Vercel de destino | A identificar/vincular |
| Projeto Supabase de destino | A identificar e autenticar |
| Serviços realmente oferecidos | Revisar no painel antes da publicação comercial |
| Tabela de serviços e materiais | Cadastrar em rascunho e aprovar antes de publicar |
| Deslocamento e regiões | Aprovar valores e cobertura |
| Descontos autorizados | Aprovar percentuais e aplicação |
| Validade, vistoria e condições de pagamento | Cadastrar/aprovar no painel |
| Entrega: regiões, prazos e cobrança | A definir; nesta versão é combinada no atendimento |
| Retirada: local e horários | A definir; sem presumir disponibilidade |
| Trocas, devoluções e cancelamento | Texto aprovado a fornecer |
| Política de privacidade e responsável pelo atendimento | Texto aprovado a fornecer |
| Termos e demais condições comerciais | Texto aprovado a fornecer |
| Contato de suporte técnico | A definir, sem número fictício |
| Responsável pela guarda dos backups | A definir |
| Aprovação da entrada em operação pública | Pendente de configuração e homologação hospedada |

Nome, contatos, categorias, apresentação e redes sociais têm campos no painel existente. Modalidades e políticas sem editor nesta versão devem ser entregues ao responsável técnico como textos aprovados; não foram criados novos módulos nesta homologação.
